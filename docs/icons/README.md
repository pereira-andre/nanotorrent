# NanoTorrent penguin icon

The original penguin holding a horseshoe magnet was created for NanoTorrent with the built-in image generation tool. The final full-resolution transparent PNG is [penguin-magnet.png](penguin-magnet.png); it is retained in the repository with the project artwork.

`scripts/build-icons.py` uses macOS `sips` and `iconutil` for image-size conversion and packages the PNG frames into a Windows ICO. It produces:

- `docs/icon.png`: 256-pixel transparent icon, embedded in the desktop window and included in Linux packages.
- `docs/NanoTorrent.icns`: macOS Dock/Finder icon with 16–1024-pixel representations.
- `src/TorrentClassic.App/app.ico`: Windows executable, taskbar and tray icon with 16, 24, 32, 48, 64, 128 and 256-pixel representations.
- `src/TorrentClassic.Core/Remote/icon.png`: 128-pixel remote-panel branding and browser favicon.

## Final image prompt

Use case: precise-object-edit. Asset type: finished desktop app icon.

Edit target: the supplied friendly baby penguin icon. Keep this exact original penguin character: the same face, eyes, cheerful expression, charcoal and cream body, orange beak and feet, soft illustrated shading and transparent background.

Requested change: the penguin is now proudly holding ONE large classic red U-shaped horseshoe magnet with silver tips in front of its lower chest/belly. Bring both little wings around the magnet so it is clearly being held, instead of waving. Make the magnet shape bold, simple and immediately recognizable at small icon sizes. It should be prominent without obscuring the penguin's face. The magnet relates to torrent magnet links.

Preserve the complete penguin and feet within the square, with around 10 percent transparent padding at every edge, ready for desktop icons. Maintain a genuine transparent alpha background. No background tile, no scenery, no text, no letters on the magnet, no symbols floating in the air, no added characters or objects, no watermark. Deliver one finished icon, not a sheet or mockup.
